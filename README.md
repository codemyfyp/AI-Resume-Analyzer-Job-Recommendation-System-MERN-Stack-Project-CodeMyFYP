## 📌 Project Description

The **AI Resume Analyzer & Job Recommendation System** is a smart web application developed using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.

This project helps users upload resumes, analyze skills, and receive job recommendations based on their profile. It includes AI-based resume parsing, authentication, and an admin dashboard for managing users and job listings.

This project is highly suitable for **Final Year Engineering Students (CSE / IT / AIML)** looking for an advanced and innovative project for academic submission and portfolio building.
